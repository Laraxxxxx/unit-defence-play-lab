# Publishing

This repository is published with GitHub Pages from the main branch, repository root.

- index.html is the game hub and four early prototypes.
- city.html is the self-contained City Siege campaign and endless game.
- .nojekyll disables theme processing.
- README.md and DEVELOPMENT.md describe controls, research and planned work.

Update the game files on main; the Pages workflow publishes the changes. After the workflow finishes, verify both the hub and City Siege link in a browser. The code and website are public.
