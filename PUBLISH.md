# Publish with GitHub Pages

This folder is ready to publish. `index.html` contains all four playable games and all their code. It uses no external libraries or downloaded assets.

1. Create a public repository named `unit-defence-play-lab` in your GitHub account.
2. Upload `index.html`, `.nojekyll`, and `README.md` to the root of its `main` branch. Do not upload the surrounding folder or a ZIP as the website.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**. Save.
5. Wait for GitHub to show the live website address. Share that address with your friend; no account or email is needed to play.

The repository and game source will be public. The game runs entirely in each visitor's browser, and progress is stored only on their device. It is single-player, not a multiplayer session.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
