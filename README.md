## Last Light: City Siege — v0.2

A 2D tactical zombie survival prototype with directly controlled units. Defend a fictional city using streets, wrecks, destructible roadblocks and specialist squads.

- Three campaign districts and nine assaults; endless survival continues across districts.
- Infantry, medic, flamer, grenadier, sniper, gunner, and recruitable engineer.
- Two permanent specializations per survivor, manual abilities, toxin treatment, repairs and scavenging.
- Road forecasts and three arrival groups; no preparation countdown.
- Browser-local preparation/reward checkpoints. Interrupted battles resume from preparation. Campaign and endless saves are separate.
- Four original early zombie/alien experiments remain available in the main menu.

Mouse and keyboard recommended. Click or drag to select, right-click to move/focus, A then click to attack-move, H to hold, Space to pause, Q to use the first selected unit's ability, Ctrl+A to select all. Read the in-game field manual for details.

This is a single-player development build. Balance and progression need player feedback. Multiplayer, final art, audio and a full narrative campaign are future work.

Both HTML files are self-contained. GitHub Pages publishes main / root. No build service, API keys, analytics, external assets or player accounts are required. To play offline, download both HTML files into the same folder and open index.html.

See [research and development notes](DEVELOPMENT.md) for sources, design decisions, proposed alien factions and future cooperative play. All implementation code and map drawings are original; no franchise assets or extracted game files are included.
